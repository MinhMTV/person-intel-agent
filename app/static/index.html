          How it works

          1. Reference photo. The upload is validated, EXIF orientation is applied, metadata is stripped and faces are detected. Choose the target face if several people are visible.
          2. Reverse image search (Google Cloud Vision Web Detection, optionally TinEye) finds pages containing the same photo or cropped / edited copies. This is image matching, not face recognition.
          3. Parameter-assisted discovery uses your optional hints (name, location, usernames, …) to find candidate profiles and pages.
          4. Local face matching. Images from candidate pages are downloaded safely, faces are embedded with ArcFace and compared with the target face. The cosine similarity is mapped to bands (VERY_HIGH … NO_MATCH). Bands are not probabilities; look-alikes exist.
          5. Evidence fusion. Observations (image occurrence, face similarity, name/location/username/email matches, cross-links) are combined into a descriptive level. STRONG requires several independent signals; a name or face similarity alone never does.
